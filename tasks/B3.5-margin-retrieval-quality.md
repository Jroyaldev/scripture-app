## Why this task exists (audit, 2026-07-02)

The user's verdict after using the app: "the AI notes seem random; the semantic algorithm is not magical; not structured or dependable enough for pastors." The audit confirms this is **correct** and locates the root causes precisely. The pipeline has real signal in it — it just cannot separate signal from noise, and it decorates noise with AI framing.

Key facts in this data:

- **EmbeddingGemma's cosine floor for unrelated text is ~0.5.** The fixed `0.3` threshold in `assembleSemanticMargin` (`src/core/ai/semantic-margin.ts:82`) filters **nothing, ever**. Top-5 is always full. "Small group logistics" surfaces for Leviticus 13. This is the single root cause of "the AI notes seem random."
- **Real signal exists.** The Acts 19 note scores 0.804 with a 0.12 gap over #2 — a decisive, magic-grade hit. GEN 1 legitimately pulls "Light and darkness in John's prologue" to the top (a real inter-textual echo pastors would love). The model is good; the decision layer is absent.
- The related/unrelated bands **overlap** (unrelated ceiling ~0.68, related range 0.65–0.80): no absolute threshold alone can be correct. Gap-based + calibrated logic is required.

## SOTA principles adopted (researched 2026-07-02)

Distilled from current hybrid-RAG practice and acclaimed resurfacing products (NotebookLM's citation grounding, Readwise resurfacing, Obsidian Smart Connections, production RAG stacks):

1. **Hybrid retrieval**: BM25 (FTS5) + dense candidates fused with Reciprocal Rank Fusion, `k=60`. Rank-based fusion sidesteps the incomparable-score problem. Single biggest precision lift without new models.
2. **Paragraph-level chunking**: embed 100–300-token paragraph chunks, not whole notes; aggregate per-note by best chunk. EmbeddingGemma context ceiling 512 tokens.
3. **Calibrated floor + score-gap cutoff instead of one absolute threshold**: cosine scores are not comparable across queries; keep items within a gap of the top hit AND above a corpus-calibrated noise floor.
4. **Show nothing rather than something mediocre**: an honest empty state builds more trust than 5 filler cards. This is the core "magic feeling" mechanic — magic requires the possibility of silence.
5. **MMR diversity (λ=0.5)** after scoring so top-5 isn't five near-duplicates of one idea.
6. **Deterministic why-provenance** (HUMAN DECISION 2026-07-02): every surfaced card explains itself with the best-matching paragraph snippet + concrete signals ("cites Acts 19:2", "anchored to a cross-reference of this passage", "strong phrase overlap"). No LLM in the interactive loop for reasons — free, instant, truthful.
7. **Domain signal first**: scripture-reference overlap (explicit citations, anchor proximity, TSK-graph adjacency) is fused as a first-class retrieval signal, not an afterthought.
8. **Evidence-derived claim confidence**: never display model self-reported confidence; derive from verified evidence (note-quote grounding, evidence count). Quote-anchored extraction: claims must cite short exact quotes, verified by string match against the actual note text (NotebookLM/Anthropic-citations pattern).
9. **Golden-set eval harness**: retrieval quality is regression-tested (passage→expected-notes pairs + must-NOT-surface distractors), run as a gate like lint/tests.
10. **Deferred (explicit decision, not omission)**: local cross-encoder reranker (BGE-reranker class, ~250–400MB, ~100–150ms/query) is a real precision lift but adds a second model download; revisit only if Gates R1–R3 don't clear the magic gate. LLM-written reasons rejected (latency/cost/failure-mode per margin refresh).

## The Magic Gate (acceptance definition)

The task is done when ALL of these hold on the seeded corpus (and remain true as gates in `eval:margin`):

- **M1 — Silence**: LEV 13 / PSA 23 (no related notes) show **zero** semantic notes, with the honest empty state. No filler, ever.
- **M2 — Precision**: ACT 19:1–7 surfaces the Spirit/baptism cluster with the Acts note first; the admin distractors ("Small group logistics", "Reading plan Q3") never appear for any theological passage.
- **M3 — Serendipity survives**: GEN 1 still surfaces "Light and darkness in John's prologue" (the genuine echo) — the quality bar must not sterilize discovery.
- **M4 — Every card explains itself**: each surfaced note shows a deterministic reason a pastor can verify in one glance (matching paragraph + signal chips). No raw cosine percentages anywhere in the UI.
- **M5 — Nothing circular**: no margin item is derived from the thing it claims to illuminate (suggestedCrossRefs echo removed; threads scoped to the passage).
- **M6 — Claims are grounded or absent**: every displayed claim shows verified evidence ("grounded in 2 notes", quotes verified by string match); model self-reported confidence is not displayed.

## Staged plan

### Gate R1 — Chunked embeddings + hybrid candidate retrieval
- Deterministic paragraph chunker in core (pure, INV-18): split note body on blank lines, merge tiny fragments, cap ~300 tokens (~1200 chars) per chunk. Chunk identity = `${noteId}#${index}` with per-chunk content hash.
- `embeddings-sync.ts`: embed per chunk (`src_kind = "note_chunk"`), incremental by chunk hash, prune stale chunks when a note shrinks. Keep one whole-note vector? No — per-note score = max over its chunks.
- `semantic-margin` IPC handler: fetch BM25 candidates from `notes_fts` (query = passage text keywords) alongside dense candidates; pass both ranked lists into core.
- Core RRF fusion (`k=60`) over (dense ranks, BM25 ranks, reference-signal ranks — see R2).
- Tests: chunker determinism/edge cases, chunk-level incremental sync, RRF math.

### Gate R2 — Scoring discipline: domain signal, calibration, quality bar, diversity
- Scripture-reference signal (core, deterministic): extract refs cited in note bodies + note anchors; score overlap with (a) the queried range, (b) its TSK cross-reference targets. Fused as third RRF list AND as reason chips.
- Calibration: `scripts/calibrate-margin.ts` (landed) — chunk-aware distribution report over contrasting passages; floors live in `DEFAULT_RETRIEVAL_OPTIONS` and are re-verified against this report when the model or corpus shape changes.
- Decision layer replacing the 0.3 threshold: top hit must clear the calibrated floor (start ~0.66 absolute for EmbeddingGemma per measurements, superseded by calibration) — otherwise **show nothing**; keep subsequent items only within a gap (start: 0.08) of the top RRF-fused score; MMR λ=0.5 across chunk vectors for the final list; max 5, no minimum.
- Tests: fixture-based decision-layer tests pinning the measured ACT/GEN/PSA/LEV distributions as regression fixtures.

### Gate R3 — Truthful margin surfaces (UI + assembly)
- `assembleSemanticMargin`: return `reasons` per semantic note (best chunk snippet + signal descriptors); scope threads to notes surfaced/anchored in range; DELETE the circular suggestedCrossRefs echo — replace with refs cited by surfaced related notes that are NOT already in the passage's TSK list (deduped), or hide the section entirely when empty.
- `LivingMargin.tsx`: reason line + signal chips per card; remove raw percentages; honest empty state ("No closely related notes for this passage"); "why am I seeing this" affordance = the reason itself.
- Live QA via CDP against the seeded library: walk ACT 19, GEN 1, LEV 13 and verify M1–M5 visually.

### Gate R4 — Dependable claims (feeds re-sequenced B3 Gate 3)
- `claims-v2` prompt: each claim must include 1–2 short EXACT quotes from the notes as evidence; validation verifies quotes by normalized string match against real note text — unverifiable quote = rejected claim (never repaired).
- Confidence becomes derived: verified-evidence count + anchor specificity; model self-report ignored. UI shows "grounded in N notes" with the quote(s) on expand.
- Then B3 Gate 3 (background extraction jobs) proceeds on top of this contract.

### Gate R5 — Eval harness (locks the magic gate)
- `npm run eval:margin`: golden set of passage→{must-surface, must-not-surface} pairs over the seeded corpus (extend seed corpus to ~25 notes incl. more distractors and one long multi-topic note); asserts M1–M3 + precision/recall floors; runs headless (plain-Node embedding path).
- Wire into the verification flow next to lint/test in this file and `STATUS.md`.

### Deferred / revisit triggers
- Local cross-encoder reranker: only if eval shows precision@5 gaps after R1–R3.
- Feedback loop (dismiss/pin adjusting per-user thresholds): after B3 Gate 3 lands, pin/dismiss events exist to learn from.
