# C0.2 — X-bounded corridor claims

> **Status:** Complete — 2026-07-18
> **Component:** `lab/route-engine.js` corridor occupancy contract
> **Current maturity:** L2 routing prototype with corridor-wide Y claims
> **Target maturity:** L2 precise, deterministic 2-D corridor occupancy

## Objective

Make every corridor reservation describe the horizontal ink it actually occupies.
Two routes may share a corridor Y only when their padded horizontal spans are
disjoint; overlapping spans must retain the existing deterministic separation.

This is geometric claim bookkeeping, not semantic/AI claims. It is the bounded
prerequisite for calm left/right shoulders and future section handoffs. It must
not relax obstacle clearance, the middle shaft's hard zero-crossing rule, spine
separation, density limits, or any terminal ownership exemption.

## Contract

- Corridor claims are normalized finite records:
  `{ corridor, y, xMin, xMax, pad }`, with `xMin <= xMax`.
- A candidate conflicts with a committed claim only when:
  1. both occupy the same corridor;
  2. their Y separation is below the existing claim-gap threshold; and
  3. their padded X intervals overlap.
- Claim spans come from the verified run that was actually planned. Level exits
  and local drip claims, which do not all pass through `corridorYFor`, must emit
  explicit spans too.
- Only painted/committed routes consume claims. Shadow plans remain side-effect
  free.
- Existing callers that provide a legacy claim without X bounds remain
  conservatively corridor-wide during this task; malformed finite bounds are
  never treated as permission to overlap.

## Acceptance

- Two same-corridor, same-Y claims with disjoint X spans reuse the slot exactly.
- Overlapping X spans still stagger by the existing deterministic 0.6px ladder.
- Reversed candidate endpoints normalize without changing the result.
- Same-line cradle, local tag/comb (including level exit and drip), middle shaft,
  and margin routes emit finite normalized X extents for every corridor claim.
- Disjoint left/right-shaped shoulders can coexist without weakening text or
  verse-number collision checks.
- Route-engine behavior has direct Node tests; the older `trace-geometry.js`
  suite is not accepted as proxy coverage.
- Dense Psalm, long Revelation, and middle-shaft browser fixtures retain zero
  validation failures and deterministic output across the existing width sweep.
- `node --check`, focused tests, full tests, lint, and `git diff --check` pass.

## Non-goals

- No right-margin generator or UI.
- No section-aware side switching or plural-spine route model.
- No app renderer, persistence, anchor, or Substrate changes.
- No aesthetic vocabulary changes; this task only removes false congestion.
