# C0.5 — The bracket grammar (calm terminals and handoffs)

> **Status:** landed on `codex/smart-shapes`
> **Date:** 2026-07-19
> **Kind:** visual amendment — routing legality, claims, ownership, disclosure,
> and the section solver are unchanged; this gate re-formed only how the line
> touches words and changes direction, plus the paint it is drawn with.

## Why

The C0.4 pause review judged the engine's silhouettes not clean enough to
freeze into the application, and two intermediate re-forms during this gate
were rejected at visual review as well ("not the clean soft right angle look;
never parallel with underline; you're always looping weird"). The landed
grammar is the third and simplest form.

## The grammar that landed

**One vocabulary: horizontals colinear with underlines, verticals, and one
soft rounded right-angle corner token (`CORNER = 6`, shrinking only for
measured room). Nothing slants, settles, swoops, dips, hooks, or loops.
Nothing ever runs parallel to an underline at an offset.**

- **Margin route (the bracket):** every group is ONE level run straight off
  its underline — colinear, threading every dot in the group — plus ONE soft
  corner at the rail. The route's bottommost group (and the final section's)
  turns UP into the rail; every other group turns down with the flow. When
  the whole route is one group (a tag, a same-line pair, a local rail), the
  line simply ENDS at the rail datum — no corner, no drip: a corner exists
  only where the rail genuinely connects two runs. The run breaks at every
  dot, so each contact is a true vertex.
- **Blocked is held:** underline-level travel is vetoed only by RAW measured
  ink (expanded clearance skirts are passed under a raw-guarded envelope
  exempt), and a vetoed or claim-blocked run reports `needs-space` honestly.
  The old drop/shoulder family — a parallel line offset below the underline —
  no longer exists.
- **Same-line cradle:** the squared hammock — level lead off pin A, soft
  corner down, wall, soft corner onto one genuinely flat floor, then the
  exact mirror rising level into pin B. Facing and embrace share the
  identical grammar. `GAP_FACING_MIN` = 18, `GAP_EMBRACE_MAX` = 24.
- **Section handoff:** straight rail continuation → soft corner → one
  genuinely horizontal run centered in the declared gap → mirrored corner →
  straight rail continuation. "S" names the topology, not a glyph.
- **Middle shaft:** host-disabled (`allowMiddle: false` in Shapes); its
  interior jog failed the visual gate. It may return only speaking this
  grammar.
- **Paint:** one clean uniform stroke, round caps and joins, in both lab
  hosts. The calligraphic swell profile is retired. Kind only chooses hue.

## Safety story

The envelope exempt is the one new privilege: it admits passage through
*expanded clearance skirts* only, bounded by the drawn level run (±0.75px
vertically), and every envelope-excused sample is re-checked against the
obstacle's RAW measured rect. Real-ink crossing remains impossible;
`needs-space` remains the honest answer when the clean shape is illegal.
`minimumClearance` reads near zero on legal routes because the grammar
intentionally occupies the skirts it is licensed to pass — the hard gates are
the raw-ink guard and non-excused expanded sampling, unchanged.

## Production post-integration hardening — 2026-07-20

The first integrated build exposed both a native launch failure and production
fidelity/performance gaps that the isolated lab could not reveal. They are now
classified and corrected without changing the frozen ownership contracts.

- The captured macOS crash is an AppKit `_RegisterApplication` `SIGABRT`
  before application JavaScript, not an out-of-memory failure. The Electron
  ABI preflight and full app launch pass in the GUI-authorized environment.
  Local-only Crashpad and JSONL lifecycle records now preserve evidence for
  future renderer, child-process, library-cutover, and shutdown failures.
- Real memory risks were removed: library switches are transactional and
  retire the prior runtime only after publication; authored revision draining
  is independent from semantic work; embedding inference is serialized,
  split into bounded batches, capped at eight waiting batches, tied to the
  exact sender/session/generation, and recycled through one hidden host; Git
  binary detection reads only the first 8 KiB.
- The app had flattened the four lab tools into generic progressive cards and
  measured against a stale nominal width. Palette again exposes its complete
  relationship and pigment vocabulary when the live stage supports it; Rail
  is silent at rest; Radial is a 320px arrow-roving wheel or a narrow labeled
  sheet; Dock regains a neutral sliding mode thumb. Semantic color stays in
  glyphs, swatches, and connection ink rather than button edges.
- The editable connection card now opens in-flow inside Living Margin instead
  of covering Scripture. Its persistent Study heading owns initial and return
  focus. Removing the transient card entrance animation and input autofocus
  fixes the retained detached-card path found through the document animation
  timeline.
- Route layout caches both word obstacles and exact anchor fragments. The
  anchor key includes durable identity, canonical coordinates, package, and
  the complete phrase locator; geometry, typography, theme, chapter, or
  package changes invalidate the whole cache, and removed anchors are pruned.

Live Electron verification covers Palette, Pen Rail, Radial, and Dock at

a 332px stage. All eight presentations stay inside the viewport with zero
